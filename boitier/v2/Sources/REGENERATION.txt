Dépendances : Python 3.12, cadquery, sexpdata, trimesh. Depuis Sources : python enclosure/build.py puis python enclosure/case.py. Les sorties sont dans enclosure/deliverable. Les scripts de téléchargement conservent les URL sources. Les paramètres mécaniques sont en tête des scripts. Les fichiers BREP/maillages intermédiaires sont régénérés. Blender est optionnel pour les aperçus.
Pour refaire le recalage photographique : placer les deux photos originales dans Sources/upload avec leurs noms d’origine, puis lancer enclosure/photo_height.py. Dépendances supplémentaires : scipy, numpy, Pillow, matplotlib. Les photographies originales restent les pièces fournies dans la conversation ; les comparaisons annotées sont incluses dans le dossier.
